# آپارتمان سوم: پلان دوبعدی، تور ۳۶۰ پرشی و مدل سه‌بعدی اسکچ

ورودی: ۲۶ عکس با لنز عریض گوشی و یک ویدئوی گردش ۸۲ ثانیه‌ای از همین خانه.

| فایل | چیست |
|---|---|
| `index.html` | تور ۳۶۰ با ۹ نقطه + پلان دوبعدی (دکمه‌ی «پلان») |
| `sketch.html` | مدل سه‌بعدی خطی: نمای سه‌بعدی، نمای از بالا، قدم زدن |
| `home.js` | داده‌ی پلان؛ از `tools/home_data.py` ساخته می‌شود |
| `panos/` | ۹ پانورامای ۳۶۰ (۴۰۹۶×۲۰۴۸) |

## اجرا

```bash
cd apartment-3 && python3 -m http.server 8000
# http://localhost:8000/            تور ۳۶۰ و پلان
# http://localhost:8000/sketch.html مدل سه‌بعدی اسکچ
```

## روش

1. **پلان** (`tools/home_data.py`): از روی عکس‌ها و ویدئو. ۹ فضا، حدود ۹۶ متر مربع. اندازه‌ها تخمینی‌اند (عرض درها، کاشی‌های حدود ۶۰ سانتی و مبلمان).
2. **ویدئو:** با خط تولید `property-reconstruction-mvp` بازسازی شد: ۳۶۰ از ۴۳۸ فریم کلیدی جا افتاد (۸۲٪) و فقط ۲ پرش تند داشت. پلان خودکار آن هنوز خام بود (یک فضای ۴۶ متری، بدون جداسازی اتاق‌ها)، پس فقط برای کنترل شکل کلی استفاده شد.
3. **پانوراما:** طرح راهنمای ۳۶۰ از روی پلان (`tools/guides.py`) به‌اضافه‌ی عکس‌های همان فضا به مدل تصویر داده شد (`tools/render_pano.py`، Gemini 3.1 Flash Image از OpenRouter، خروجی 4K).
4. **حریم خصوصی** (`tools/privacy.py`): عکس‌ها و پوسترهای شخصی روی دیوار به قاب ساده تبدیل شدند و تصویر عکاس در آینه‌ی سرویس پاک شد.
5. **هم‌جهت‌کردن** (`tools/align.py`): دو پانوراما که مدل کمی چرخانده بود با پلان هم‌جهت شدند.

## هزینه

۹ پانوراما × حدود ۰٫۱۵۴ دلار = **حدود ۱٫۴ دلار**. پردازش ویدئو روی سرور (حدود ۷ دقیقه) و بقیه‌ی مراحل هزینه‌ی مدل نداشتند.

## محدودیت‌ها

- **پانوراماها ساخته‌ی هوش مصنوعی‌اند، نه عکس ۳۶۰ واقعی.** جاهایی که در هیچ عکسی نیست حدسی است و هندسه‌ی پانوراما با پلان کاملاً یکی نیست. مثلاً در اتاق خواب ۲، در و پنجره نزدیک‌تر از واقعیت به هم کشیده شده‌اند.
- **چیدمان اتاق‌ها نسبت به هم برآورد است.** جای دقیق اتاق‌خواب‌ها و حمام در انتهای راهرو از روی عکس‌ها قطعی نیست.
- **اولین نسخه‌ی پلان قرینه بود.** آشپزخانه و پذیرایی جابه‌جا بودند. مقایسه‌ی پانوراماها با طرح راهنما این را نشان داد و درست شد.
