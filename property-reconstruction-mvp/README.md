# بازسازی ملک از عکس و ویدئو — نسخه‌ی سبک فاز صفر

این پوشه نسخه‌ی سبک و کامل خط تولید سند «AI Property Reconstruction & Virtual Tour Platform» (نسخه‌ی ۱٫۱) است.
یک بار از ورودی خام تا تور سه‌بعدی قابل گردش اجرا می‌شود تا شکاف‌ها پیش از ساخت اپلیکیشن اصلی روشن شوند.
نتیجه‌ی آزمون‌ها در [RESULTS.md](RESULTS.md) آمده است.

## اصل‌ها در کد

- **اول واقعیت:** رنگ هر نقطه از کف و دیوار مستقیم از عکس‌های واقعی برداشته می‌شود. هیچ پیکسلی ساخته‌ی هوش مصنوعی نیست (`generated_pixels: 0`). جایی که هیچ دوربینی ندیده خاکستری می‌ماند و در نمایشگر علامت می‌خورد.
- **قابل راستی‌آزمایی:** هر اتاق، هر برچسب و هر بافت فهرست عکس‌هایی را که از آن آمده نگه می‌دارد. در نمایشگر می‌شود در هر ایستگاه مدل سه‌بعدی را روی عکس واقعی همان نقطه انداخت و مقایسه کرد.
- **ماژولار:** هر مرحله خروجی خودش را در پوشه‌ی اجرا می‌نویسد و اگر خروجی موجود باشد دوباره اجرا نمی‌شود.

## مراحل (موتورها)

| مرحله | فایل | کار |
|---|---|---|
| A. پیش‌پردازش | `recon/preprocess.py` | خواندن عکس‌ها (چرخش EXIF، تکراری‌ها، تاری، تاریکی)؛ از ویدئو فریم‌های کلیدی را با معیار وضوح و میزان جابه‌جایی برمی‌دارد |
| C. هندسه | `recon/geometry.py` | ساختار از حرکت با COLMAP: ویژگی SIFT، تطبیق ترتیبی برای ویدئو و کامل برای عکس، نقشه‌برداری افزایشی |
| پلان | `recon/layout.py` | جهت بالا، کف، سقف، زاویه‌ی غالب دیوارها، فضای آزاد، جداکردن اتاق‌ها، دیوار و در؛ خروجی `scene.json` |
| D. ظاهر | `recon/texture.py` | بافت کف و دیوار از بهترین عکس واقعی برای هر نقطه |
| E. معنا | `recon/semantic.py` | نام اتاق با مدل بینایی از روی عکس‌های همان اتاق، همراه با درصد اطمینان و عکس‌های شاهد |
| ارزیابی | `recon/evaluate.py` | مقایسه با بازسازی مرجع: درصد ثبت فریم، خطای جای دوربین، هم‌پوشانی پلان |
| خروجی وب | `export_web.py` + `viewer/index.html` | بسته‌ی داده و نمایشگر سه‌بعدی |

## اجرا

```bash
python -m venv venv && . venv/bin/activate
pip install -r requirements.txt          # و ffmpeg روی سیستم

# فقط عکس
python run.py --out runs/photos --photos path/to/photos
# فقط ویدئو
python run.py --out runs/video --video walk.mp4
# هر دو، با نام اتاق‌ها (نیاز به OPENROUTER_API_KEY)
python run.py --out runs/both --video walk.mp4 --photos path/to/photos --stages pre,sfm,layout,texture,semantic
```

اگر عکس‌ها اطلاعات لنز (EXIF) ندارند، `--focal-factor 0.45` حدس اولیه‌ی فاصله‌ی کانونی را می‌دهد (نسبت به عرض تصویر).

## نمایشگر

```bash
python export_web.py runs/video viewer/data
cd viewer && python -m http.server 8000
# http://localhost:8000/        یا با مسیر دیگر:  ?data=path/to/bundle/
```

- **نمای کلی و پلان:** دیوارها از نیمه بریده می‌شوند تا داخل دیده شود.
- **ایستگاه‌ها:** روی هر نقطه‌ی نارنجی بزنید. دوربین به جای و زاویه‌ی همان عکس می‌رود و لغزنده بین مدل و عکس واقعی جابه‌جا می‌کند.
- **قدم زدن:** با کلیدهای W/A/S/D یا جهت‌ها راه بروید. دیوارها مانع عبورند.
- **نشان‌دادن نادیده‌ها:** بخش‌هایی را که هیچ عکسی پوشش نداده راه‌راه می‌کند.

## داده‌ی آزمایشی

آزمون‌ها روی صحنه‌ی «nyc» از مجموعه‌داده‌ی پژوهشی Zip-NeRF انجام شد (۹۹۰ عکس پشت‌سرهم از گردش در یک آپارتمان).
مجوز انتشار مجدد این تصاویر روشن نشد، پس هیچ عکس یا بافتی از آن در مخزن نیست. فقط کد، عددها و نمودارهای پلان اینجاست.
`experiments/prepare_nyc.py` ورودی‌های آزمون را از آن داده می‌سازد.
